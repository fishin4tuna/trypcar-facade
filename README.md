# TrypCar Website

The official website for TrypCar, a members-only campus mobility network.
Live at https://trypcar.com

## What this is
A static website: plain HTML, CSS, and JavaScript with no build tools,
frameworks, or databases. Every file can be opened and edited in any text
editor, and the site runs on any standard web host.

## Hosting
Hosted free on GitHub Pages from this repository. The CNAME file connects
the custom domain trypcar.com.

## Key files
- index.html: home page, waitlist form, and intro animation
- trypcar.css: shared styles and design colors for every page
- about, support, faq, contact: information pages
- ride, reserve, hubs, lux, eco, scootz: service pages
- terms, privacy: legal pages (kept out of search results)
- sitemap.xml, robots.txt: search engine guidance
- google8da39b464a48a317.html: Google Search Console verification (do not delete)

See the TrypCar Handover Guide (PDF) for full instructions.
